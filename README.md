# AX Discrimination Analysis

R analyses from a speech-perception experiment examining listeners' discrimination of non-native speech contrasts.

## Analyses

The repository contains three complementary analyses of AX discrimination performance:

- **Logistic regression** of trial-level discrimination accuracy
- **d-prime analysis** to quantify discrimination sensitivity independently of response bias
- **Reaction-time analysis** of response speed across experimental conditions

## Files

### `discrimination_logistic_regression.R`
Analyzes binary correct/incorrect AX responses using logistic regression.

### `Dprime_Codes.R`
Calculates signal-detection sensitivity measures from discrimination responses.

### `reaction_time_analysis.R`
Analyzes reaction-time patterns in the AX discrimination task.

## Methods and Skills Demonstrated

- Behavioral speech-perception analysis
- Binary outcome modelling in R
- Logistic regression
- Signal Detection Theory / d-prime
- Reaction-time data analysis
- Data filtering and preprocessing
- Statistical interpretation and visualization

## Research Context

The analysis forms part of research on non-native speech perception and listeners' sensitivity to acoustic-phonetic contrasts.

## Software

Analyses were conducted in **R** using standard statistical and data-manipulation packages.
